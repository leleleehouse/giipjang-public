# 기입장

편한가계부 엑셀 파일을 분석하고 저축·투자 계좌를 관리하는 개인용 가계부입니다. 거래와 계좌 정보는 실행하는 컴퓨터의 SQLite 데이터베이스에 저장됩니다.

## 시작하기

Node.js 20 이상이 필요합니다. 터미널에서 다음 명령을 순서대로 실행하세요.

```sh
npm ci
npx prisma db push
npm run dev
```

브라우저에서 http://localhost:3000 을 열고 엑셀 파일을 업로드하거나 저축·투자 계좌를 추가하세요. 처음에는 데이터가 없는 빈 가계부로 시작합니다. 월별 예산은 예산 관리에서 직접 설정합니다.

데이터는 `prisma/ledger.db`에 저장됩니다. 백업하려면 서버를 종료한 후 이 파일을 별도 위치에 복사하세요. 데이터베이스, 엑셀, CSV와 환경 변수 파일은 Git에 포함되지 않도록 설정했습니다.

## 기능

- 엑셀 가져오기와 월별·연간 소비, 카테고리 및 결제 수단 분석
- 대분류와 소분류의 일회성 지출 설정 및 예산 관리
- 저축·투자 계좌, 납입 목표와 보유 종목 관리
- 현재 시세와 환율을 이용한 투자 평가, 자산 성장 추이 및 시뮬레이션

투자 계좌의 과거 평가액은 매수일과 현재 보유 수량, 월말 시세를 이용한 추정치입니다. 과거 매도·수량 변경이나 현금은 반영하지 않으며 시세나 매수일이 없으면 해당 값을 표시하지 않습니다. 저축 금액은 누적 원금 기준이며 이자와 정부기여금이 포함되지 않을 수 있습니다.

시세 조회에는 Yahoo Finance, 환율 조회에는 Frankfurter를 사용합니다. 조회하려는 종목 코드는 외부 서비스에 전송됩니다.

## 사용 범위

서버는 `127.0.0.1:3000`으로 실행되며 로그인이나 사용자별 데이터 분리 기능이 없는 개인용 프로그램입니다. 인터넷에 공개하거나 여러 사람이 같은 서버를 공유하는 용도로 사용하지 마세요. 누구나 각자의 컴퓨터에 설치해 별도 데이터로 사용할 수 있습니다.
